Before protection starts, here is exactly what happens.

The extension reads the message text you are about to send and checks it against detection patterns in your browser. If something is found, the send is held. Nothing is changed or sent unless you choose it.

Your text stays in the browser. Two routine background requests never carry message content: a daily check for the signed detection configuration, and with a Pro license a daily license check. Detection patterns can be updated by the developer through the signed configuration. The source code is public.
